# UniDots design system handoff

Give this folder to Claude Code (put it in the repo, e.g. `design/`, then say: "Read design/CLAUDE.md and apply it to this app").

- `CLAUDE.md`: the instructions
- `docs/SCREENS.md`: every screen with screenshot and notes
- `standalone/*.html`: open in a browser to see each screen live
- `screenshots/`: reference images
- `screens/`, `components/`, `tokens/`, `assets/`: source
